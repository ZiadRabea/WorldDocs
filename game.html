Simple Game



Simple game :


A two-player Russian roulette style guessing game written in WorldLang. It imports the Random module to generate a secret target number dynamically, passes prompt messages directly inside استقبل_رقم, and utilizes newline sequence escapes (\n). 


استدعاء("Random")

متغير الرقم_العشوائي = توليد_رقم_عشوائي(1, 10)
